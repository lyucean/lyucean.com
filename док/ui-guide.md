# UI-гайд Lyucean

Единый визуальный язык сайта. Любой новый блок сверять с этим файлом.

## Голос бренда

Скетчбук CIO: графит, бумага, спокойная сетка. Не маркетплейс, не соцсеть, не Bootstrap-demo.

## Токены

Источник правды: CSS-переменные `--ly-*` в `style.css`.

| Токен | Роль |
| --- | --- |
| `--ly-paper` | фон страницы |
| `--ly-paper-elevated` | карточки, сегменты статьи, футер-лента |
| `--ly-ink` | основной текст и акценты |
| `--ly-ink-muted` | мета, подписи, вторичное |
| `--ly-rule` | тонкие границы |
| `--ly-cover-ratio` | `1024 / 671` для обложек |
| `--ly-radius` | мелкий радиус (не «пилюли» везде) |
| `--ly-shadow-soft` | лёгкая тень оболочки |

Запрещено как акцент интерфейса: bootstrap primary/success/danger, радуга соцсетей, красный `#` у тегов, фиолетовый glassmorphism на обложках.

## Оболочки

1. **Страница** = `--ly-paper`.
2. **Контент** (пост, сегмент поста после divider, статическая страница) = `.post-shell` на `--ly-paper-elevated` + `--ly-rule`.
3. **Разделитель статьи** (`article-divider`) обязан открывать снова `.post-shell`, не голый `article.rounded`.
4. **Блоки под постом** (feedback, related) = не клоны `.post-shell`. Фон страницы, без elevated-карточки: у feedback вопрос + кнопки по центру, без rule сверху/снизу; у related eyebrow + список с линиями.
5. **Футер** = тот же `--ly-paper` + одна elevated-панель `.footer-web-projects__panel` (как карточки главной). Без полноширинной «чужой» серой ленты и без россыпи отдельных боксов.

## Картинки

| Тип | Правило |
| --- | --- |
| Обложка поста (featured) | `aspect-ratio: 1024/671`, `object-fit: cover`, на всю ширину shell, без UI-штампов |
| Обложка page | тот же принцип, допускается `21/9` с `max-height` |
| Картинки внутри статьи | ширина колонки, `max-height: 28rem`, `object-fit: contain`, по центру, без «гигантских» портретов на весь экран |
| Превью в related / главной | фиксированный кадр, cover |

Нельзя: бейджи/blur поверх обложки; картинка hero меньше ширины shell; inline без ограничения высоты.

## Типографика и мета

- Заголовок поста: один H1 в `.post-header`.
- Мета: слева `дата N мин`, справа в конце строки `N чит.`, без разделителей `·`. muted.
- Теги: в конце статьи (`.post-tags`), muted `#tag`, без красного. Не в шапке поста.
- Ссылки в тексте: ink + underline, не синий default.
- Summary / blockquote: графитная полоска слева, без primary/success.

## Компоненты

- **Главная сетка**: `.post-card`, обложка по `--ly-cover-ratio`.
- **Feedback**: вопрос + кнопки по центру, одна высота (`2.25rem`), без white-card и без rule; Да/Нет ghost, Комментарий ink.
- **Related**: eyebrow «Ещё статьи» + список с линиями, не оболочка статьи.
- **Мои проекты**: одна elevated-панель как карточки сайта, 4 колонки с rule внутри.
- **Футер-бар**: копирайт слева, `telegram instagram email rss` текстом справа.
- **Сайд-навигация** поста: тихие icon-кнопки, не Bootstrap btn.
- **Теги в сайдбаре**: `.front-tags`, топ-15 по count, только `#tag` lowercase, без заголовка и без счётчиков; после меню, до block-menu.
